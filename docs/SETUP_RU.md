# Как начать пользоваться YaFormCreator

Это инструкция для человека, который впервые создаёт анкету. Редактор работает на компьютере. Интернет, организация и токен понадобятся при нажатии «Создать в Яндексе».

## 1. Установите и откройте приложение

1. Откройте [страницу выпусков](https://github.com/TeenKode/ya-form-creator/releases).
2. Если есть готовый выпуск, скачайте `YaFormCreator.exe` из его раздела Assets. При отсутствии выпуска сборку можно найти в GitHub Actions → успешный Build Windows EXE & release → Artifacts. Для скачивания артефакта может потребоваться вход в GitHub; скачанный ZIP нужно распаковать.
3. Создайте личную папку, например «Документы\Мои анкеты», и поместите EXE туда. Приложению нужно право записывать файлы рядом с EXE.
4. Запустите приложение. Установка Python для EXE не требуется.

Если запускаете исходники: установите Python 3.12 с сайта python.org, откройте папку проекта и запустите `START_WINDOWS.bat`. Альтернатива: `py -3 -m pip install -r requirements.txt`, затем `py -3 app.py`.

## 2. Соберите первую анкету без токена

1. Нажмите «Настройки анкеты» и введите название. Здесь же задаются текст кнопки отправки и сообщение после ответа.
2. Нажмите «Добавить вопрос». Выберите понятный тип: «Один вариант», «Несколько вариантов», «Текст», «Число» или «Дата».
3. Введите вопрос. Для вариантов ответа пишите каждый вариант на отдельной строке.
4. Код вопроса программа предлагает автоматически. Обычно менять его не нужно. Он связывает вопросы и условия показа.
5. Включите «Обязательный ответ», если вопрос нельзя пропустить. Для уточнения свободного ответа используйте «Добавить поле “Другое”».
6. Сохраните вопрос. Добавьте остальные вопросы; изменяйте их двойным нажатием, меняйте порядок стрелками.
7. Нажмите «Сохранить» и выберите имя JSON-файла. Даже пустую анкету можно сохранить как заготовку.
8. Откройте «Предпросмотр», попробуйте разные ответы и нажмите «Проверить ответы». Данные из этого окна никуда не отправляются.

После открытия приложение может восстановить последнюю сохранённую анкету. Для пустого проекта нажмите «Новая». При несохранённых изменениях можно сохранить их, продолжить без сохранения или отменить действие.

### Как настроить ветвление

Например, вопрос «Укажите адрес доставки» нужен только выбравшим «Доставка»:

1. Сначала добавьте вопрос с выбором способа получения, затем вопрос про адрес.
2. Откройте «Условия показа». В поле «Какой вопрос показывать» выберите адрес.
3. В качестве предыдущего вопроса выберите способ получения. Отметьте ответ «Доставка».
4. Оставьте «Совпадает» и «Любой из выбранных», нажмите «Добавить правило», затем «Сохранить условия».
5. Проверьте оба сценария в предпросмотре.

«Все выбранные» полезно для нескольких одновременно выбранных флажков. Несколько отдельных правил одного вопроса должны выполняться вместе. Зависимый вопрос должен находиться после источника. Поле «Другое» получает своё условие автоматически.

## 3. Выберите организацию

Для API нужны **Формы для бизнеса**. Личная форма и один только Яндекс ID не заменяют организацию. Если организация уже есть, попросите администратора дать вашему аккаунту доступ и узнайте её тип и идентификатор.

| Что у вас есть | Организация в приложении | Способ входа |
| --- | --- | --- |
| Яндекс 360 для бизнеса | Яндекс 360 для бизнеса | OAuth — Яндекс ID |
| Yandex Cloud / Identity Hub, обычный Яндекс ID | Yandex Cloud / Identity Hub | OAuth — Яндекс ID или пользовательский IAM |
| Yandex Cloud, федеративный аккаунт | Yandex Cloud / Identity Hub | IAM — Yandex Cloud |

Доступ к API зависит от прав самого пользователя. Авторизация сервисным аккаунтом Yandex Cloud для этого приложения не подходит. Основание: [документация доступа к API](https://yandex.ru/support/forms/ru/api-ref/access).

### Вариант А. Организация Яндекс 360

1. Войдите в Яндекс под аккаунтом будущего владельца организации.
2. Откройте [кабинет администратора](https://admin.yandex.ru) и начните регистрацию организации.
3. Заполните данные владельца и организации. Следуйте актуальному процессу подключения и выбора тарифа в кабинете.
4. Уточните стоимость и условия до оплаты: приложение не оформляет подписку за вас. По текущей инструкции Яндекса этот путь предусматривает выбор тарифа и оплату доступа.
5. Откройте [Формы для бизнеса](https://forms.yandex.ru/cloud/admin), войдите как владелец или сотрудник. Если организаций несколько, выберите нужную через меню аккаунта.
6. В приложении выберите «Яндекс 360 для бизнеса». Это соответствует заголовку API `X-Org-Id`.

Подробности и изменения процесса: [Подключить Формы для бизнеса](https://yandex.ru/support/forms/ru/enable-forms). Создание организации прямо на странице Форм может создать организацию Cloud: проверяйте её фактический тип, а не выбирайте 360 по привычке.

### Вариант Б. Организация Yandex Cloud / Identity Hub

1. Откройте [Yandex Identity Hub](https://org.yandex.cloud) под своим Яндекс ID.
2. Если организации ещё нет, создайте её по [официальной инструкции](https://yandex.cloud/ru/docs/organization/operations/enable-org): задайте название и необходимые данные, подтвердите создание в кабинете.
3. Если работаете в организации коллеги, примите приглашение и согласуйте доступ с администратором.
4. Откройте Формы для бизнеса и убедитесь, что выбрана эта организация и создание форм доступно вашему аккаунту. Само наличие облачной организации не гарантирует доступ к каждой функции сервиса.
5. В приложении выберите «Yandex Cloud / Identity Hub». Ему соответствует `X-Cloud-Org-Id`.

Не создавайте облако, виртуальную машину или сервисный аккаунт только ради локального редактора. Для него нужны пользовательский доступ к Фoрмам и идентификатор организации.

## 4. Найдите ID организации

ID организации — отдельное значение. Оно не совпадает с названием компании, логином, ClientID OAuth-приложения, ID облака или каталога.

- Универсальный путь из документации Форм: [Яндекс Трекер](https://tracker.yandex.ru) → Администрирование → Организации → поле идентификатора.
- Для 360 идентификатор также доступен в кабинете организации. Если не видите его, обратитесь к администратору.
- Для Cloud используйте карточку организации в Identity Hub и [инструкцию по идентификатору](https://yandex.cloud/ru/docs/organization/operations/organization-get-id).

Скопируйте значение без кавычек и пробелов. При нескольких организациях сверьте название выбранной организации в Формах.

## 5. Получите OAuth-токен

Этот способ подходит для обычного Яндекс ID. Токен — секрет, разрешающий приложению действовать от имени вашего аккаунта. Не присылайте его в Issues, чаты и скриншоты.

1. Войдите в аккаунт, которому доступна нужная организация.
2. Откройте [Яндекс OAuth](https://oauth.yandex.ru), создайте приложение **для доступа к API или отладки**.
3. Заполните название, например YaFormCreator, и контактную почту.
4. Добавьте разрешения `forms:read` и `forms:write`, создайте приложение.
5. Откройте карточку приложения и скопируйте **ClientID**. Это ID приложения; в поле организации он не подходит. Client secret этому редактору не нужен.
6. Откройте адрес ниже, заменив `ВАШ_CLIENT_ID` полученным значением:

```text
https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
```

7. Разрешите запрошенный доступ под аккаунтом участника нужной организации. Скопируйте выданный токен.
8. В YaFormCreator при создании выберите «OAuth — Яндекс ID» и вставьте **только токен**, без слова OAuth.

Источник и актуальные названия полей: [Как получить доступ к API Яндекс Форм](https://yandex.ru/support/forms/ru/api-ref/access). `forms:read` нужен для проверки доступа, `forms:write` — для создания. Если меняете разрешения приложения, получите новый токен.

## 6. Если нужен IAM-токен

Этот способ работает только с Cloud. Используйте пользовательский токен, не токен сервисного аккаунта.

1. Настройте вход своего аккаунта в Yandex Cloud по [официальной инструкции IAM](https://yandex.cloud/ru/docs/iam/operations/iam-token/create).
2. Если Yandex Cloud CLI уже установлен и настроен на нужного пользователя, выполните:

```powershell
yc iam create-token
```

3. Скопируйте результат в поле токена, выберите «IAM — Yandex Cloud» и организацию «Yandex Cloud / Identity Hub».
4. Укажите ID организации. При истечении токена получите новый. Такой токен временный; сохранение в приложении не продлевает срок его действия.

Для федеративной учётной записи используйте процесс входа и профиль CLI, выданные вашим администратором. Не заменяйте их случайным OAuth-токеном другого аккаунта.

## 7. Создайте форму

1. Нажмите «Проверить», затем сохраните анкету.
2. Нажмите «Создать в Яндексе». Укажите тип организации, способ входа, токен и ID.
3. По умолчанию токен не сохраняется. Отметка «Запомнить» сохраняет его без шифрования рядом с приложением. Используйте её только в личной папке.
4. Проверьте название, число элементов и режим публикации в подтверждении.
5. Дождитесь окончания. В результате есть ссылки с кнопками открытия и копирования.
6. По умолчанию создаётся **черновик**. Откройте редактирование в Яндексе, проверьте вопросы и доступ, затем опубликуйте форму там. Только после этого отправляйте ссылку участникам.

Каждое создание делает новую форму. Приложение не обновляет существующую форму и не загружает из неё изменения обратно. Локальный JSON и форма в Яндексе — независимые копии.

## 8. Частые проблемы

| Проблема | Что проверить |
| --- | --- |
| 401: нет авторизации | Срок токена, аккаунт, отсутствие префикса OAuth/Bearer в поле токена. Для IAM получите свежий токен. |
| 403: нет прав | Разрешения forms:read и forms:write, участие пользователя в нужной организации, доступ к Фoрмам для бизнеса. |
| Организация не найдена | Тип 360/Cloud, выбранная организация, её ID вместо ClientID/ID облака. |
| 400/422: API не принял данные | Выполните локальную проверку. Для расширенных API-вопросов сверьте поля с текущим справочником Яндекса. |
| 429: слишком много запросов | Подождите. Перед повтором проверьте кабинет, чтобы не создать дубликат. |
| Сбой сети | Проверьте интернет и доступ к api.forms.yandex.net. Не отключайте проверку TLS. |
| Форма создана частично | Откройте ссылку черновика из ошибки. Уже добавленные вопросы сохраняются в Яндексе. Завершите работу там либо удалите ненужный черновик самостоятельно. |
| Истёк таймаут при создании | Сервер мог принять запрос. Сначала проверьте кабинет Форм; повтор не является безопасным продолжением. |
| Не сохраняется JSON/токен | Переместите приложение в личную папку с правом записи. Закройте файл в других программах, проверьте свободное место. |
| Предпросмотр отличается от Яндекса | Это локальная имитация. Финально проверьте черновик в браузере. Расширенные API-поля могут не иметь локального ввода. |

Приложение намеренно не повторяет POST-запросы автоматически: иначе возможны дубликаты вопросов или форм. Автоматический откат и удаление черновиков не выполняются.

## 9. Где находятся файлы и как сбросить вход

- `user_settings.json` рядом с EXE: размер окна и последняя открытая анкета.
- `.yandex_form_credentials.json` рядом с EXE: сохранённые данные подключения, только после явной отметки.
- JSON анкеты хранится в выбранной вами папке. В нём нет токена.

Для удаления сохранённого токена используйте «Дополнительно» → «Удалить сохранённый токен». Или закройте программу и удалите файл авторизации вручную. Это удаляет локальную копию; для отзыва самого доступа используйте управление разрешениями Яндекс ID. Если токен попал к другому человеку, отзовите его и получите новый.

Переменные окружения `YANDEX_FORMS_TOKEN`, `YANDEX_FORMS_ORG_ID`, `YANDEX_FORMS_AUTH_SCHEME` и `YANDEX_FORMS_ORG_HEADER` имеют приоритет перед сохранённым файлом. Удаление файла их не очищает. По умолчанию используются OAuth и X-Org-Id; для IAM задайте Bearer и X-Cloud-Org-Id.

Не отправляйте папку приложения целиком: в ней могут быть токен, личные анкеты и пути к файлам. Для обращения за помощью достаточно версии приложения, кода ошибки и обезличенного описания.

## 10. Клавиши и дополнительные возможности

### Анкета, подготовленная ИИ

Отправьте агенту ссылку на репозиторий и описание, используя [готовый запрос](../START_HERE_AI.md). Агент должен прочитать AGENTS.md, правила JSON, справочник полей и схему. Если читать ссылки он не умеет, приложите эти документы отдельно. Специальные поля требуют версии приложения **1.1.0+** (версия указана в основном окне).

Для ФИО, телефона РФ, почты, URL, ИНН и дробного числа выберите тип вопроса «Текст», затем его назначение в поле «Что вводит пользователь». Номера заказов, документов и индексы храните как обычный однострочный текст: это сохраняет ведущие нули. Для международного телефона тоже используйте обычный текст. Подробности — [справочник полей](FIELD_GUIDE_RU.md).

`full_name` не требует отчества и не проверяет личность; `phone` использует формат РФ. Проверка формата не гарантирует уникальность ответа среди респондентов. Неизвестное назначение «номера» необходимо уточнить. В версии 1.0.0 поля format игнорировались: обновите EXE, прежде чем создавать такие формы.

### Клавиши

- Ctrl+N — новая анкета; Ctrl+O — открыть; Ctrl+S — сохранить.
- Ctrl+Shift+S — сохранить под другим именем; F5 — предпросмотр.
- Enter или двойное нажатие на вопрос — редактирование; Delete в списке — удаление с подтверждением.
- Меню «Дополнительно» открывает JSON анкеты, отдельного вопроса и условий показа.
- Для подготовки анкеты через ИИ используйте [AI_JSON_RULES.md](../AI_JSON_RULES.md), затем обязательно проверьте JSON в приложении.

Документация проверена 6 ноября 2026 года. Интерфейс и условия сервисов Яндекса могут изменяться; ссылки на первоисточники приведены в каждом разделе.
