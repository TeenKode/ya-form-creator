Краткое описание:
Создавайте Яндекс Формы из подготовленной анкеты после проверки и подтверждения.

Полное описание:
YaFormCreator помогает перенести вопросы с сайта-конструктора в Яндекс Формы. Подготовьте анкету вручную или с помощью ИИ, проверьте вопросы в предпросмотре и создайте черновик в своём аккаунте.

Как начать:
1. Нажмите значок расширения: откроется сайт конструктора.
2. В настройках расширения войдите через Яндекс и подключите организацию Identity Hub.
3. Добавьте вопросы или откройте файл анкеты на сайте.
4. Нажмите «Создать в Яндексе». Откроется отдельная страница с вопросами и организацией: сверьте их и подтвердите создание.

В расширении есть пошаговое подключение и отдельное окно подтверждения. Оно создаёт форму и вопросы через API Яндекса в фоновом процессе только после вашего подтверждения. По умолчанию создаётся черновик; публикация включается отдельно. После завершения вы получите ссылку для редактирования.

Возможности:
• Текст, имя, телефон РФ, почта, выбор ответов и другие типы вопросов.
• Подготовка анкеты с ИИ по единому файлу правил: ключ ИИ не требуется.
• Подключение Identity Hub без ручного получения IAM-токена.
• Подхват видимого ID из выбранной вкладки кабинета и ручной ввод как запасной способ.
• Токен остаётся в расширении, не передаётся сайту или автору проекта.

Требования: компьютер, обычный Яндекс ID и доступ к Формам для бизнеса в организации Identity Hub. Федеративные аккаунты, которым требуется IAM, не поддерживаются. Условия и стоимость сервисов определяет Яндекс. Каждый запуск создаёт новую форму; редактирование существующих форм этим расширением не поддерживается.

Независимый проект, не является официальным продуктом Яндекса или Opera.
