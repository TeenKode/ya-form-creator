# Ревью сайта 1.6.3 и расширения 1.6.2

Проверены сайт, импорт JSON, общий формат, локальный предпросмотр, подтверждение создания формы, авторизация и граница сайта/расширения. Настольный движок проверяется общими контрактными тестами; ручной прогон всего EXE не выполнялся.

## Найденные и исправленные проблемы

| Приоритет | Сценарий и последствие | Исправление |
| --- | --- | --- |
| P1 | Организация или аккаунт менялись после открытия подтверждения. Создание брало текущее подключение, хотя пользователь видел другое. | Подтверждение связано с сеансом входа и ID организации. При изменении подключение нужно подтвердить заново, отметка публикации снимается. Фоновый процесс проверяет связь перед запросами. После запуска показывается организация именно этой операции. |
| P2 | Пользователь выходил во время незавершённого OAuth-входа, но поздний ответ снова сохранял доступ. Два параллельных входа также могли перезаписать друг друга. | Входы имеют отдельные попытки, выход отменяет их. Проверка и сохранение подключения выполняются последовательно; устаревшие ответы не сохраняют токен. |
| P2 | Кнопка входа другим аккаунтом могла повторно использовать уже разрешённый вход без возможности выбрать аккаунт. | Запрашивается явное подтверждение через force_confirm, предусмотренное Яндекс OAuth. |
| P2 | JSON проходил первичную проверку, но ломался при развёртке исключающих вариантов и условий. Некорректная анкета успевала заменить рабочую копию. | Полная локальная развёртка проверяется до замены и сохранения анкеты. Ошибка оставляет прежнюю анкету и ответы. |
| P2 | Явная проверка расширения могла повторно использовать незавершённый старый запрос и показать неверный результат после обновления. Двойное нажатие отправки создавало несколько подтверждений. | Перед отправкой и по кнопке обновления выполняется свежая проверка; параллельная подготовка заблокирована. |
| P2 | Предпросмотр позволял отметить больше вариантов checkbox, чем max_choices. Число ответов было понятно только при финальной проверке. | Показаны границы и счётчик. После достижения максимума нельзя выбрать остальные варианты; снятие отметки снова разрешает выбор. Минимум проверяется с понятным сообщением. Учитываются условные вопросы и «Другое». Границы доступны в редакторе. |
| P2 | Обязательный checkbox с max_choices: 0 создавал невыполнимое требование. | Такой набор отклоняется Python-движком, JavaScript-движком и JSON Schema; необязательный max_choices: 0 остаётся допустимым. |
| P2 | Проверка ИНН в браузере учитывала длину, но пропускала неверные контрольные цифры. | Добавлена проверка контрольных цифр, согласованная с настольной версией. Это не проверка регистрации или принадлежности ИНН. |

## Дополнительно по замечаниям пользователя

Основной запрос ИИ требует готовый JSON текстом. Видимая кнопка «Вставить ответ ИИ» открывает и выделяет поле ручного редактирования JSON. Блок Markdown принимается, если он один и содержит корректный JSON. Не нужно требовать у бесплатного чата прикреплённый файл. Короткие правила остаются ограничены по длине, полная схема доступна отдельно.

## Проверки

- Локальная сборка сайта/расширения/магазинного ZIP и Node-проверки.
- В CI: Python-проверки на Ubuntu и Windows, браузерные сценарии Chromium и официальной Opera 139.0.6053.38.
- Регрессии: смена организации между подтверждением и созданием без запросов API; сброс публикации; выход во время входа и параллельные входы; отсутствие ID организации в ответах публичному сайту; неправильные контрольные цифры ИНН; невозможные лимиты; сохранение прежней анкеты при ошибке развёртки; текстовый импорт и счётчик checkbox.
- Браузерные проверки выполняются в изолированных профилях с синтетическими ответами Яндекса. На компьютере пользователя тестовые окна не запускаются.

Параметры обмена кода на токен, PKCE без Client secret и force_confirm сверены с [документацией Яндекс OAuth](https://yandex.ru/dev/id/doc/ru/codes/code-url).

## Что этим ревью не подтверждено

Живой OAuth и создание формы в реальном аккаунте не выполнялись. Тесты не оценивают понимание документов реальными бесплатными моделями. Окончательные проверки ответов выполняет Яндекс. Отправка версии 1.6.1 в Opera подтверждена, но одобрение магазина не является результатом этого ревью. Изменения расширения требуют отдельной установки 1.6.2 и обновления магазинной заявки.
