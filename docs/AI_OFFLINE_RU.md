# Короткое задание для чата с ИИ

1. На [сайте](https://teenkode.github.io/ya-form-creator/) нажмите **«Создать с ИИ» → «Скопировать задание»**.
2. Вставьте текст в свой чат и добавьте описание анкеты или документ. Вместо вставки можно прикрепить [короткий TXT](https://teenkode.github.io/ya-form-creator/ai-instructions.txt).
3. Получите form.json и откройте его на сайте. Текстовый ответ можно вставить в «Дополнительно» → «Применить изменения»; один JSON-блок с тройными обратными кавычками тоже поддерживается.
4. Сверьте вопросы с заданием и попробуйте заполнить предпросмотр.

Основной текст содержит только задачу, небольшой набор правил и один пример. Полная JSON Schema и инструкции установки программ в него не входят. Для необычных настроек отдельно доступен [подробный справочник](https://teenkode.github.io/ya-form-creator/ai-reference.txt).

Если ответ не принимается, отправьте сообщение об ошибке в тот же чат и попросите исправить предыдущий JSON, сохранив вопросы. Незавершённый ответ нужно попросить прислать целиком. Несколько JSON-блоков сайт не объединяет автоматически.

Копирование задания не включает вашу открытую анкету, ответы, организацию или токен. Вы сами выбираете, что отправить в сторонний сервис. Не передавайте ИИ секреты. Качество зависит от модели: короткий текст и проверка формата не гарантируют понимание каждого исходного документа.
