# Если ИИ не умеет открывать GitHub

Доступ к ссылкам зависит от конкретного чата и его инструментов. Файлы репозитория не могут включить этот доступ. Пользоваться конструктором можно и без него.

1. Откройте [сайт](https://teenkode.github.io/ya-form-creator/) и нажмите **«Создать с ИИ»**.
2. Нажмите **«Скопировать правила»** и вставьте текст в чат ИИ. Либо скачайте **один TXT-файл** и прикрепите его к сообщению. [Скачать файл напрямую](https://teenkode.github.io/ya-form-creator/ai-instructions.txt).
3. Следующим сообщением отправьте описание анкеты или свой документ. Если чат ограничивает длину вставки, используйте вложение TXT, если он умеет читать файлы.
4. Получите `form.json`. Если ИИ выдаёт только текст, скопируйте JSON без Markdown в блок «Дополнительно» на сайте и нажмите «Применить изменения».
5. Нажмите «Проверить», сверьте вопросы и попробуйте заполнить предпросмотр. Проверки не заменяют сверку с заданием.

TXT содержит правила, справочник полей и полную JSON Schema. ИИ не нужно открывать ссылки или получать код проекта. Если чат не может прочитать даже текст или вложение, смените способ передачи или чат; гарантировать поддержку всех бесплатных сервисов нельзя.

Копирование правил не передаёт в ИИ открытую на сайте анкету, ответы, организацию или токен. Вы сами выбираете, какое задание отправить в сторонний сервис. Токен для генерации JSON не нужен.

Для разработчиков: TXT собирается автоматически из `docs/AI_PROMPT_HEADER_RU.md`, `AI_JSON_RULES.md`, `docs/FIELD_GUIDE_RU.md` и `schema/form.schema.json` командой `python scripts/build_browser.py`. Не редактируйте сгенерированный файл отдельно.
