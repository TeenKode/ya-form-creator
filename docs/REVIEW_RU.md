# Ревью и исправления

Дата: 6 ноября 2026 года. Исходная ревизия: `36a7274`. Проверены движок, редактор, предпросмотр, CLI, сборка и документация. Ниже перечислены обнаруженные проблемы и принятые решения.

## Исправленные ошибки

| Приоритет | Проблема | Исправление |
| --- | --- | --- |
| P1 | Скрытый вопрос участвовал в вычислении видимости и мог включать зависимые поля; его контролы также отображались | Скрытые поля исключены из видимости и отображения, включая автоматически создаваемое «Другое». |
| P1 | Переименование кода вопроса оставляло ссылки в условиях на прежний код | Ссылки на источник, цель и дополнительное поле переименовываются вместе; весь кандидат проверяется до применения. |
| P1 | Перемещение вопроса могло поставить источник условия после зависимого вопроса | Перед применением проверяется копия документа; некорректное перемещение отклоняется без изменения анкеты. |
| P1 | Внешние ошибки могли включать токен и попадать в журнал/диалог | Токен и Authorization удаляются из сообщений о сетевых и HTTP-ошибках; добавлены регрессионные проверки. |
| P1 | Некорректный ответ API после создания формы мог привести к необработанному исключению без ссылки на черновик | Формат ответа проверяется; ошибки заполнения после создания сохраняют ссылку на частичный черновик. Публикация при ошибке не выполняется. |
| P2 | Массив или объект вместо типа вопроса, ссылки условия, оператора или варианта «Другое» вызывал TypeError | Типы проверяются до операций с множествами и словарями; пользователю возвращается ConfigError. |
| P2 | Неверный validators расширенного вопроса проходил проверку и ломал построение payload | Проверяется список объектов с непустым type. |
| P2 | Неканоничные даты принимались Python, но не соответствовали заявленному YYYY-MM-DD | Формат и календарная корректность проверяются отдельно. |
| P2 | Длинная корректная цепочка условий могла исчерпать стек рекурсии | Убрана рекурсивная проверка: требование предшествования источника уже исключает циклы. Тестируется цепочка из 1100 вопросов. |
| P2 | Для одиночного выбора задавался виджет, но не серверный валидатор single | Добавлен single для radio, dropdown, scale, stars и onerow; checkbox сохраняет множественный выбор. |
| P2 | Пустую анкету нельзя было сохранить и восстановить | Пустые заготовки разрешены при открытии/сохранении; API-создание по-прежнему требует элементов. |
| P2 | Генератор кодов не учитывал имена автоматически создаваемых дополнительных полей | Выделение кодов резервирует основной код и код дополнительного поля; дублирование проверяет весь документ. |
| P2 | При смене кода расширенного API-вопроса payload.slug оставался прежним | Код в payload обновляется вместе с основным. |
| P2 | Обработчики Ctrl+N/O/S были глобальными и могли менять документ при открытом модальном редакторе | Горячие клавиши выполняются только из основного окна. |
| P2 | Неверная кодировка файла давала исключение вместо ошибки открытия | UnicodeError преобразуется в понятную ошибку конфигурации. |
| P2 | Ноль считался отсутствующим числовым ответом в локальной проверке | Отсутствие значения отделено от значения 0. |
| P2 | Программа автоматически пробовала другой тип организации при любой ошибке доступа | Выбранный тип организации соблюдается; IAM с организацией 360 отклоняется до сети. |
| P2 | Собственная HTTP-сессия оставалась незакрытой | Сессия закрывается контекстным менеджером; переданная вызывающим кодом сессия остаётся под его управлением. |
| P2 | Не было возможности сохранить изменения из предупреждения перед закрытием/открытием | Добавлены три выбора: сохранить, продолжить без сохранения, отменить. Неудачное сохранение отменяет исходное действие. |

Дополнительно проверяются логические флаги, текстовые поля, конечные значения баллов и отсутствие пробелов/переносов строк в данных авторизации. Значение `other: null` не ломает визуальный редактор.

## Интерфейс

- Единая светлая палитра, контрастные акценты, крупные заголовки и более просторные строки списка.
- Шаги «Соберите анкету → Проверьте ответы → Создайте в Яндексе», стартовый экран и подсказки без требования токена при локальной работе.
- Карточка вопроса с читаемыми вариантами вместо JSON; технические редакторы сохранены в меню «Дополнительно».
- Русские названия типов, прокручиваемый редактор вопроса, визуальный конструктор условий.
- Понятные названия типов организации и входа, скрытый токен с переключателем отображения, инструкция рядом с полями.
- Индикатор операции, ссылки с открытием и копированием, явное различие между черновиком и опубликованной формой.
- PNG и многоразмерный ICO: от 16 до 256 пикселей; иконка встроена в окно и ресурс Windows EXE.
- Подробная инструкция включена в автономную сборку и открывается без сети.

## Проверка

Выполнено `python -m unittest discover -v -p "test*.py"`: **46 тестов проходят**, включая GUI-тесты Tkinter на Windows. Новые проверки покрывают ошибки JSON, сохранение заготовок, изменения условий, выделение кодов, отказ API, сокрытие токена и запрет публикации частичного результата.

Интерфейс основного окна, редактора вопроса и встроенной инструкции осмотрен через Windows Computer Use. По результатам исправлены размеры панелей, резервирование места для нижней панели и применение шрифтов. Ввод через средства компьютерного управления в модальном Tk-окне не подтвердился; сбор данных из контролов проверен GUI-тестами.

Однофайловая Windows-сборка создаётся PyInstaller с PNG/ICO и локальной документацией. CI сохраняет существующие проверки отсутствия анкет и токенов в репозитории.

## Границы проверки

Реальный OAuth/IAM-токен и организация не предоставлялись. Запросы создания/публикации в живом API не выполнялись. Сценарии API проверены подставной HTTP-сессией, а формат параметров и инструкция сверены с официальными источниками:

- [Доступ к API и права](https://yandex.ru/support/forms/ru/api-ref/access).
- [Формы для бизнеса и подключение организации](https://yandex.ru/support/forms/ru/enable-forms).
- [Создание вопроса и серверные валидаторы](https://yandex.ru/support/forms/ru/api-ref/questions/events_b2b_v1_views_questions_create_question_public_view).
- [Условия показа](https://yandex.ru/support/forms/ru/api-ref/display-conditions/events_b2b_v1_views_conditions_create_question_condition_public_view).

Предпросмотр остаётся имитацией: расширенные API-вопросы и окончательная семантика Яндекса требуют проверки в созданном черновике. Сохранение токена остаётся добровольным и незашифрованным; Windows ACL/защищённое хранилище этой версией не реализованы. POST-запросы не повторяются автоматически, частичные формы не удаляются. При таймауте сначала проверьте кабинет, поскольку сервер мог принять запрос.
