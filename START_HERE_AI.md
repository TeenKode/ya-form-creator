# Создать анкету для YaFormCreator

Для обычной анкеты достаточно [короткого задания AI_SHORT_RU.md](AI_SHORT_RU.md). В нём есть формат, пример и правила для имени, телефона, почты и номеров документов. Не нужно читать несколько файлов или запускать программы до генерации.

Если чат не читает GitHub, на [сайте](https://teenkode.github.io/ya-form-creator/) нажмите **«Создать с ИИ» → «Скопировать задание»**. Или приложите [короткий TXT](https://teenkode.github.io/ya-form-creator/ai-instructions.txt). Затем добавьте описание анкеты. Правила не дают ИИ доступ к ссылкам автоматически.

Запрос для агента с доступом к репозиторию:

```text
Прочитай AI_SHORT_RU.md в https://github.com/TeenKode/ya-form-creator
и верни JSON текстом по моему заданию ниже. Сохрани вопросы, порядок,
варианты, обязательность и условия. Если чего-то существенно не хватает,
кратко уточни. Не заполняй ответы и не обращайся к Яндексу.
Моё задание: ...
```

Для расширенных параметров используйте [полную спецификацию](AI_JSON_RULES.md), [справочник полей](docs/FIELD_GUIDE_RU.md) и [схему](schema/form.schema.json). На сайте они доступны отдельным [расширенным TXT](https://teenkode.github.io/ya-form-creator/ai-reference.txt), который не нужен для каждого запроса.

Если код проекта и выполнение команд уже доступны, проверьте результат через `python check_agent_form.py --config form.json` и `python create_yandex_form.py --config form.json --dry-run`. Это дополнительная проверка, а не требование к обычному чату. Не утверждайте, что выполняли её, если не запускали.

Откройте результат на сайте и сверьте его с заданием. Проверка структуры не доказывает правильное понимание любого документа или выполнение правил каждым ИИ. Специальные текстовые форматы требуют YaFormCreator 1.2.0+.
