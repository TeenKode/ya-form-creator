# Создать анкету по ссылке на этот репозиторий

Пользователь может отправить ИИ эту ссылку и описание своей анкеты:

```text
https://github.com/TeenKode/ya-form-creator
```

## Готовый запрос для любого ИИ с доступом к ссылкам

Скопируйте текст ниже и добавьте своё задание или документ:

```text
Создай JSON-анкету для YaFormCreator по правилам репозитория
https://github.com/TeenKode/ya-form-creator .

Сначала открой AGENTS.md, START_HERE_AI.md, AI_JSON_RULES.md,
docs/FIELD_GUIDE_RU.md и schema/form.schema.json в актуальном main.
Если не можешь прочитать репозиторий, прямо скажи об этом:
не придумывай его формат. Я смогу приложить эти файлы отдельно.

Из моего задания сохрани все вопросы, варианты, порядок, обязательность
и условия. Не заполняй анкету за респондента. ФИО, телефон, почту,
ИНН, ссылки и номера документов обрабатывай по FIELD_GUIDE_RU.md.
Не превращай телефон или идентификатор с ведущими нулями в число.
Если «номер», формат телефона или требование уникальности неоднозначны,
сначала задай краткие уточняющие вопросы. Не вводи собственные ограничения.

Подготовь файл form.json в UTF-8. Если можешь запускать код, выполни
python -m pip install -r requirements-dev.txt
python check_agent_form.py --config form.json
python create_yandex_form.py --config form.json --dry-run
и исправь ошибки. Никаких токенов, запросов к живому API и публикации.
Результат после уточнений — только JSON-файл, без Markdown внутри него.

Моё задание:
[вставьте описание или приложите документ]
```

## Порядок чтения для агента

1. [AGENTS.md](AGENTS.md) — процесс и границы действий.
2. [AI_JSON_RULES.md](AI_JSON_RULES.md) — полный прикладной формат.
3. [FIELD_GUIDE_RU.md](docs/FIELD_GUIDE_RU.md) — выбор полей, неоднозначности и ограничения.
4. [JSON Schema](schema/form.schema.json) — машиночитаемый структурный контракт.

Если GitHub не отдаёт содержимое, можно читать исходный файл по адресу `https://raw.githubusercontent.com/TeenKode/ya-form-creator/main/` с добавленным путём файла. Например: [сырые правила](https://raw.githubusercontent.com/TeenKode/ya-form-creator/main/AI_JSON_RULES.md).

## Что гарантирует проверка

`check_agent_form.py` проверяет структуру через движок и ищет типичные ошибки назначения полей по их подписям. Она не доказывает, что ИИ точно понял любой документ, не находит все пропущенные вопросы и не проверяет доступ к Яндексу. Сопоставьте итог со своим заданием и откройте предпросмотр.

Форматы специальных полей поддерживаются с версии **1.2.0**. Для них используйте актуальный EXE из [Releases](https://github.com/TeenKode/ya-form-creator/releases/latest). В предыдущих версиях эти дополнительные поля формата игнорируются.

Без возможности читать ссылки ни один файл репозитория сам по себе не заставит ИИ следовать правилам: приложите правила к сообщению. В [описании проверок](docs/AGENT_CHECKS_RU.md) перечислены проверяемые случаи и границы результата.
