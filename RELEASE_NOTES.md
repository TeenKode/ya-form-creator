# YaFormCreator v1.5.0

- Мастер Identity Hub: открывает Cloud Center, пользователь сам подтверждает создание, затем расширение находит организацию и проверяет доступ к Формам перед сохранением ID.
- Сравнивает ранее найденные ID с текущим списком только при том же токене. При неоднозначном результате предлагает выбор; при смене аккаунта не объявляет старые организации новыми.
- Поддержан вход в мастер до получения IAM-токена; поиск доступен после его подключения. Шаг можно закрыть без удаления организаций.
- Организации, соглашения, подписки и платные ресурсы автоматически не создаются: в публичном Organization API нет метода Create. Справка доступна на сайте.

## Версия 1.4.0

- Вход без предварительного ввода ID: организации Яндекс 360 находятся после авторизации и выбираются по названию. Единственный вариант сохраняется автоматически после проверки доступа к Формам.
- Для Cloud добавлен поиск по пользовательскому IAM-токену. Ручной ввод ID сохранён на случай недоступного списка или недостаточных прав.
- Список организаций и выбор доступны только внутри расширения, привязаны к текущему аккаунту и не передаются сайту. Контакты организаций не сохраняются.
- Основной сайт стал короче: «Открыть анкету», «Сохранить анкету», техническое редактирование в «Дополнительно», краткая помощь ИИ.
- Обновите расширение и войдите заново, чтобы разрешить чтение организаций. Владельцу общего OAuth-приложения нужно добавить `directory:read_organization`.

- Справка по установке, организациям, входу, токенам и созданию форм открывается на сайте.
- Основной интерфейс стал короче; настройки OAuth-приложения и ручного токена перенесены в раскрываемые разделы.
- Проверены копирование правил, ручной способ при блокировке буфера, отсутствие данных открытой анкеты в тексте и переходы по справке.

## Версия 1.3.0

## Сайт и расширение без сервера

- Новый веб-интерфейс: импорт и сохранение JSON, вопросы вручную, интерактивный предпросмотр и условия, автосохранение рабочего JSON в браузере.
- Расширение Manifest V3: токен отдельно от сайта, подключение OAuth + PKCE или ручным OAuth/IAM-токеном, явное подтверждение создания и отдельное согласие на публикацию.
- Поддержка ФИО, телефона, почты, ИНН, URL, дробных чисел, матриц, «Другое» и исключающих вариантов по общему контракту настольной версии.
- Сборка ZIP, публикация на GitHub Pages, инструкция установки / организаций / OAuth / приватности. Расширение устанавливается распакованным, в магазинах не опубликовано.
- Проверки Python/JS payload, фонового обмена и ошибок API, изолированный Chromium E2E с синтетическим API. Тесты не используют реальные аккаунты и не создают живых форм.

## Предыдущая версия 1.2.0

## Анкета по ссылке для ИИ-агента

- AGENTS.md, START_HERE_AI.md с готовым запросом, справочник выбора полей и JSON Schema.
- Команда `python check_agent_form.py --config FILE.json` проверяет контракт, строит API payload без сети и сообщает о типичных ошибках назначения и логики вопросов.
- В правилах объяснено, когда уточнять запрос, как не потерять ведущие нули, почему ФИО не требует обязательного отчества и чем код поля отличается от уникальности ответов.

## Специальные поля

- Для text добавлен format: plain, full_name, phone (РФ), email, url, inn, decimal.
- Формат выбирается в редакторе, сохраняется при изменении вопроса и отображается в карточке.
- Телефон, почта, ссылка, ИНН и дробное число получают штатный валидатор Яндекс API; предпросмотр выполняет предварительную локальную проверку.
- Номера заказов/документов, индексы и международные телефоны остаются строками. ФИО — строка без выдуманной проверки имени.
- Неподдерживаемые unique/validators/pattern на уровне вопроса и числовые границы decimal отклоняются вместо молчаливой потери ограничений.

- [Справочник полей](https://github.com/TeenKode/ya-form-creator/blob/v1.2.0/docs/FIELD_GUIDE_RU.md).

**Новые форматы требуют версии 1.2.0+. Предыдущие версии игнорируют format.** Проверяются программный контракт и синтетические сценарии, а не все ИИ-модели. Реальное создание формы с пользовательским токеном в тестах не выполняется. Проверяйте JSON по исходному заданию и итоговый черновик в Яндексе. Проверка формата не подтверждает личность, существование контакта или уникальность ответа среди участников.

## Сохранено из 1.1.0
- Анализ логических противоречий **между разными вопросами** анкеты.
- Диалог «Проверка логики…» / F6: объяснения, список замечаний, кнопки «Применить выбранное» и «Применить все предложения».
- Перед проверкой и созданием формы показываются предупреждения о вероятных противоречиях.
- Добавляются только явно подтверждённые условия показа; пользовательские вопросы, ответы и уже существующие сложные условия не переписываются.
- Проверка работает локально без передачи анкеты ИИ-сервисам.

## Сохранено
- Универсальный JSON-конструктор; отсутствие готовых анкет в репозитории и EXE.
- Защита от несовместимых ответов внутри одного вопроса.
- Портативные настройки и credentials в папке рядом с `YaFormCreator.exe`.

## Проверка
- Offline-тесты логики и совместимости; Windows one-file сборка в GitHub Actions.
- Реальное создание форм в Яндексе не тестируется в CI без личных credentials.

> Правила эвристические: сложные смысловые связи могут остаться незамеченными. Проверяйте предварительный просмотр и черновик Яндекс Формы.
