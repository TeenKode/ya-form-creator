Ваши данные и доступ к Яндексу

YaFormCreator — независимый инструмент автора TeenKode. Сайт и расширение помогают подготовить анкету и создать форму в вашем Яндексе.

Какие данные используются

Сайт хранит рабочую копию анкеты и описание формы для ИИ в браузере. Кнопка «Скопировать запрос для ИИ» копирует инструкцию и ваше описание в буфер обмена. Вы сами выбираете чат и отправляете запрос; сайт не обращается к ИИ автоматически. Ответы в предпросмотре остаются в памяти страницы. Скачанные вами файлы остаются на компьютере.

При входе расширение получает от Яндекса разрешение на чтение и изменение настроек Форм. Данные входа хранятся в расширении до завершения сеанса браузера. Если включить «Запомнить вход на этом компьютере», они сохраняются в профиле браузера до выхода или удаления данных расширения. Пароль Яндекса вводится на странице Яндекса; расширение его не получает.

Также расширение хранит выбранный ID организации и настройки подключения. Для подтверждения и выполнения операции оно временно сохраняет анкету, состояние создания и ссылки на результат в сеансе браузера. После завершения создания эти записи могут оставаться до очистки старых операций или завершения сеанса.

Куда передаются данные

После вашего подтверждения расширение отправляет анкету, данные авторизации и ID организации непосредственно в API Яндекс Форм. Обработкой созданных форм и ответов участников управляет Яндекс. Вход выполняется через Яндекс OAuth. Условия Яндекса доступны в его политике конфиденциальности.

Сайт не получает токен или ID организации из расширения. Автору проекта не отправляются анкеты, токены или ответы. В приложении нет рекламы, аналитики и продажи данных. GitHub размещает сайт и загружаемые файлы и может обрабатывать обычные сведения HTTP-запросов, включая IP-адрес, по правилам GitHub. Яндекс и браузер могут отдельно обрабатывать данные по собственным условиям.

Кнопка правил для ИИ копирует правила формата, без вашей анкеты и подключения. Документы и задания вы отправляете выбранному ИИ самостоятельно; их обработка зависит от этого сервиса.

Как удалить данные

  • Нажмите «Выйти из аккаунта» в подключении: расширение удалит сохранённые данные подключения и мастера. Это не удалит созданные формы, временные операции или рабочую копию анкеты на сайте.
  • Чтобы отозвать выданное разрешение, удалите доступ приложения в настройках безопасности Яндекс ID.
  • Очистка данных сайта удалит рабочую копию анкеты. Завершение сеанса браузера очищает временные данные расширения; удаление расширения удаляет его локальное хранилище.
  • Скачанные файлы удаляются вами с компьютера, созданные формы — в Яндекс Формах.

На общем компьютере не сохраняйте вход. Хранилище расширения не является отдельным зашифрованным сейфом: защищайте свой профиль браузера.

Для чего расширению доступ

  • Хранилище — для подключения и операций создания формы.
  • Авторизация — для входа через Яндекс в отдельном окне браузера.
  • Сайт YaFormCreator — для передачи анкеты на подтверждение и получения статуса операции.
  • Яндекс OAuth и API Форм — для входа и создания формы.
  • Cloud Center и Identity Hub — чтобы по вашей кнопке прочитать только видимый ID организации в открытой мастером вкладке.

Расширение не читает историю посещений, пароли или cookies кабинета. ID организации определяется из текста страницы, без внутреннего API Яндекса. Если на странице несколько ID, расширение просит указать нужный вручную.

Связаться с автором

Вопросы о работе и данных можно направить через обращения в репозитории проекта. Обращения публичны: не прикладывайте токены, пароли, анкеты с личными данными и ответы участников.

English summary for users and reviewers

YaFormCreator is an independent tool maintained by TeenKode. The website stores the working questionnaire and the AI brief locally in the browser. Copying the prompt puts the instructions and brief on the clipboard; users choose their AI chat and send it themselves. The website does not call an AI provider automatically. Preview answers stay in page memory. The extension stores a Yandex OAuth access token, organization ID and connection preferences in extension storage. Session storage is the default; persistent storage requires the remember checkbox. Pending jobs, questionnaire content and result links can remain in session storage until cleanup or browser session end.

After explicit confirmation, the extension sends the questionnaire and authentication information directly to Yandex Forms API. OAuth is handled by Yandex. The public website cannot read credentials or organization IDs from the extension. The maintainer receives no questionnaires, tokens or answers. There are no analytics, ads or data sales. GitHub hosts static files and may process standard request metadata under its own privacy policy. Yandex, browser and any AI service chosen by the user apply their own policies.

The cabinet reader returns only a visible organization ID on demand from the wizard tab; it does not access cookies, passwords or private cabinet APIs. Logout removes saved connection data, not created forms or website drafts. Revoke access in Yandex ID security settings. Clear site data to remove the local draft; uninstall the extension to remove its local data. Delete downloaded files and Yandex forms separately. Public support: repository issues; never include secrets or personal data.
