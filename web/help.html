От первой анкеты до готовой формы

Подготовьте вопросы, проверьте их и сохраните форму в своём Яндексе.

1. Начните с анкеты

Добавьте вопросы вручную или нажмите «Создать с ИИ». Если у вас уже есть файл JSON, откройте его кнопкой «Открыть анкету».

Справа появится предпросмотр: попробуйте заполнить поля и пройти разные варианты ответов. Для сохранения копии на компьютер нажмите «Сохранить анкету».

Открыть конструктор →

2. Подготовьте анкету с ИИ

  1. На главной странице нажмите «Создать с ИИ».
  2. Скопируйте задание и правила в чат. Или скачайте один TXT-файл и прикрепите его к сообщению.
  3. Следующим сообщением опишите свою анкету или приложите документ. Ответьте на уточняющие вопросы ИИ, если они появятся.
  4. Попросите вернуть файл form.json и откройте его в конструкторе. Если ИИ вернул текст, вставьте чистый JSON в «Дополнительно» и нажмите «Применить изменения».
  5. Сверьте формулировки, варианты ответов и обязательные поля со своим заданием. Нажмите «Проверить» и попробуйте заполнить предпросмотр.

ИИ не нужен доступ к GitHub: все правила уже включены в текст. Если чат не принимает длинное сообщение, попробуйте приложить TXT. Возможности чтения файлов зависят от выбранного чата.

Скачать правила для ИИ

Для составления анкеты ИИ не нужны ваш токен и данные входа.

3. Установите расширение

Расширение нужно один раз установить на компьютере, чтобы создавать формы в Яндексе.

  1. Скачайте расширение и распакуйте ZIP в постоянную папку.
  2. Откройте управление расширениями: chrome://extensions в Chrome, edge://extensions в Edge или раздел расширений Яндекс Браузера.
  3. Включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите папку с файлом manifest.json.
  4. Обновите страницу конструктора. Появится надпись «Расширение подключено».

Расширение пока устанавливается из ZIP, в магазинах браузеров его нет. Используйте актуальный Chrome на компьютере. В Edge и Яндекс Браузере доступность входа зависит от версии; мобильные браузеры и Firefox не поддерживаются.

Не удаляйте папку расширения. Для обновления замените в ней файлы новой версией, нажмите «Обновить» в управлении расширениями и перезагрузите страницу конструктора.

4. Выберите организацию

Для создания форм через этот инструмент нужны Формы для бизнеса. Если организация уже есть, войдите в Яндекс и выберите её по названию в настройках расширения. Если список недоступен, ID можно указать вручную.

Яндекс 360 для бизнеса

  1. Войдите под аккаунтом будущего владельца в кабинет администратора Яндекс 360.
  2. Начните регистрацию организации, заполните необходимые данные. Условия подключения и стоимость проверьте в кабинете перед оплатой.
  3. Откройте Формы для бизнеса и выберите нужную организацию.
  4. Скопируйте ID организации из её кабинета или запросите его у администратора.

Yandex Cloud / Identity Hub

  1. Откройте кабинет Identity Hub под своим Яндекс ID.
  2. Создайте организацию: укажите название, заполните нужные данные и подтвердите создание. Если вас пригласили в существующую организацию, примите приглашение.
  3. В карточке организации скопируйте её ID.
  4. Откройте Формы для бизнеса и проверьте, что ваш аккаунт может создавать формы в этой организации.

При нескольких организациях сверяйте выбранное название. ID организации отличается от её названия, ClientID приложения, ID облака и каталога.

Создайте организацию Identity Hub

Если организации ещё нет, в настройках расширения нажмите «Создать организацию Cloud». Откроется мастер и вкладка Cloud Center.

  1. В Cloud Center войдите в свой аккаунт, нажмите «Создать новую организацию» и укажите название и описание.
  2. Проверьте условия у Яндекса и подтвердите создание самостоятельно.
  3. Откройте Формы для бизнеса и убедитесь, что новая организация доступна вашему аккаунту.
  4. Вернитесь в расширение. Для поиска Cloud-организаций подключите пользовательский IAM-токен через «Или вставить готовый токен» — как подключить.
  5. Нажмите «Я создал организацию — найти её». Если новый вариант определён однозначно, расширение проверит доступ к Формам и подставит ID. Иначе выберите нужное название из списка.

Мастер не создаёт облака, виртуальные машины, платёжные аккаунты или подписки. Создание организации не означает бесплатность подключённых сервисов: их условия смотрите у Яндекса.

Закрытие мастера не удаляет организации. Если доступ к Формам не подтверждён, сначала проверьте их подключение в выбранной организации, затем повторите поиск.

5. Подключите Яндекс

  1. На главной странице нажмите «Настроить подключение».
  2. Выберите тип своей организации.
  3. Нажмите «Войти через Яндекс» и разрешите работу с Формами и чтение организаций.
  4. Выберите организацию по названию. Если она одна, выбор сохранится автоматически после проверки доступа. Кнопка «Найти мои организации» обновляет список.
  5. Нажмите «Проверить доступ», затем вернитесь к анкете.

ClientID сервиса уже заполнен — обычно менять его не требуется. Каждый пользователь входит в собственный аккаунт. Если список недоступен, раскройте «Указать ID вручную». Для поиска организаций Cloud нужен пользовательский IAM-токен; его можно вставить в разделе ниже.

Если у вас уже есть токен

В настройках расширения раскройте «Или вставить готовый токен». Выберите OAuth для обычного Яндекс ID или IAM для Yandex Cloud, вставьте токен без слова OAuth / Bearer и сохраните подключение. Для федеративного аккаунта может потребоваться IAM.

Получить OAuth-токен вручную
  1. Войдите в нужный аккаунт и откройте Яндекс OAuth.
  2. Создайте приложение «Для доступа к API или отладки», укажите название и контактную почту.
  3. Добавьте разрешения «Просмотр настроек форм» (forms:read) и «Изменение настроек форм» (forms:write).
  4. В карточке созданного приложения скопируйте ClientID.
  5. Откройте адрес ниже, заменив ВАШ_CLIENT_ID своим значением. Полученный токен вставьте только в расширение.
https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
Получить IAM-токен

Используйте пользовательский IAM-токен аккаунта с доступом к нужной организации Cloud. Если Yandex Cloud CLI уже установлен и настроен на этого пользователя, выполните:

yc iam create-token

Выберите в расширении Yandex Cloud и IAM. После истечения срока токена получите новый. Сервисный аккаунт для этого приложения не подходит.

Настроить собственное OAuth-приложение

Это нужно только владельцу сервиса или пользователю собственного приложения.

  1. В Яндекс OAuth создайте приложение «Для авторизации пользователей».
  2. Выберите платформу «Веб-сервисы» и укажите Redirect URI из раздела «Настройки OAuth-приложения» в расширении.
  3. Добавьте разрешения forms:read, forms:write и directory:read_organization для поиска организаций Яндекс 360.
  4. Скопируйте ClientID в тот же раздел расширения. Client secret вводить не нужно.

Для текущей распакованной сборки адрес возврата:

https://ojjljnbbienealjljlfklnfdpfemmlli.chromiumapp.org/oauth

Если установленная сборка показывает другой адрес, используйте его. В отладочном типе приложения адрес verification_code фиксирован; для автоматического входа создайте приложение для авторизации пользователей.

6. Настройте вопросы

В списке «Ваши вопросы» можно изменить вопрос, удалить его или переместить стрелками. Если перемещение нарушает условия показа, программа предупредит об этом.

  • ФИО / имя: не требует обязательного отчества.
  • Телефон РФ: для российских номеров. Для международного телефона выберите обычный текст.
  • Почта, ссылка, ИНН, дробное число: выберите соответствующее назначение текстового поля.
  • Номер документа или заказа: используйте текст, чтобы сохранить нули в начале.
  • Целое число: для количества и других арифметических значений.

Для условий, матриц и дополнительных параметров используйте «Дополнительно» или попросите ИИ подготовить их по правилам. Проверка формата не подтверждает существование почты, принадлежность телефона или уникальность ответа среди участников.

7. Создайте форму

  1. Нажмите «Создать в Яндексе».
  2. В открывшейся вкладке сверьте название, вопросы и организацию.
  3. Подтвердите создание и нажмите «Создать черновик». Если форма готова к публикации, отдельно отметьте «Сразу опубликовать».
  4. Дождитесь результата и откройте редактирование формы в Яндексе. Проверьте её перед отправкой участникам.

Каждый запуск создаёт новую форму. Не закрывайте браузер во время создания. При ошибке сначала проверьте черновик по предложенной ссылке, чтобы не создать дубликат.

На сайте можно открыть файл до 750 КБ: до 150 исходных элементов, 200 после добавления служебных полей и 300 условий. Для больших анкет используйте настольное приложение.

Если что-то не получилось

«Обновите расширение»
Нажмите кнопку обновления на сайте, скачайте и распакуйте ZIP поверх файлов установленного расширения. В управлении расширениями браузера нажмите «Обновить», затем обновите страницу сайта. При необходимости нажмите «Проверить обновление». Пока версия не проверена, отправка недоступна, но анкету можно редактировать и сохранять.
«Нужно расширение» после установки
Убедитесь, что оно включено. Обновите страницу конструктора и используйте её в обычной вкладке браузера.
Вход отменён или неверный адрес возврата
Повторите вход. Для собственного приложения проверьте адрес в настройках OAuth. Пока вход не настроен, можно использовать ручной токен.
401 — нет доступа
Войдите заново: токен мог истечь.
403 — недостаточно прав
Сверьте тип и ID организации. Попросите администратора проверить доступ вашего аккаунта к Формам.
429 — слишком много запросов
Подождите и проверьте кабинет Форм перед повтором.
Создание остановилось
Откройте частичный черновик, если ссылка появилась. Уже созданные вопросы могут сохраниться. Повторный запуск создаст новую форму.
ИИ снова просит файлы репозитория
Передайте единый TXT с правилами вместо ссылки на GitHub. Уточните, что правила уже приложены, и отправьте своё задание.

Сохранение и доступ

Рабочая копия анкеты сохраняется в этом браузере. Очистка данных сайта удалит её — сохраняйте нужные JSON-файлы на компьютер. Ответы предпросмотра не отправляются и исчезают после обновления страницы.

По умолчанию подключение действует до завершения сеанса браузера. Флажок «Запомнить токен» сохраняет доступ на этом компьютере. На общем устройстве не включайте его. «Выйти» очищает сохранённое подключение; для отзыва доступа самого приложения используйте настройки безопасности Яндекс ID.

Никому не присылайте токен и Client secret. При работе с ИИ сами выбирайте, какие документы отправлять в сторонний чат. Кнопка копирования правил не включает вашу анкету или ответы.
