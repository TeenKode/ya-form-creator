# Иконка приложения

`app-icon-source.png` — исходное изображение, созданное встроенным imagegen.
`app-icon.png` — версия 256×256 для Tkinter и документации.
`app-icon.ico` — Windows ICO с размерами 16, 24, 32, 48, 64, 128 и 256 пикселей.
Уменьшенные версии получены из исходного PNG с сохранением прозрачности.

Промпт генерации:

> Windows desktop application icon for a friendly form builder named YaFormCreator. One rounded square tile containing a simple white form sheet with two short answer lines, a small round selection control, and a confident checkmark. Clear bold silhouette readable at 16 and 32 pixels, modern softly dimensional finish, precise rounded edges, generous padding. Warm golden yellow tile with deep charcoal details, white paper, gentle highlights. Centered square composition. No letters, no words, no watermark, no existing brand logos. Transparent background outside the rounded square tile. A single icon, not a mockup.
